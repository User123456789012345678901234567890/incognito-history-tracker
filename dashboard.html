⚙️ Setup — allow the extension in Incognito

ℹ

Checking permission…

Chrome hides Incognito windows from extensions by default. This is a one-time manual toggle that only you can grant — an extension can never enable it for itself.

  1. Go to chrome://extensions
  2. Locate Incognito History Vault and click Details
  3. Switch on Allow in Incognito
  4. Close and reopen your Incognito windows so the service worker attaches to them

The manifest uses "incognito": "spanning", so a single service worker and a single storage area serve both profiles. That is what lets your Incognito log survive after the Incognito window closes.

🗑️ Auto-delete retention

Entries older than the window are removed automatically (checked every 30 minutes, on browser start, and whenever you change this setting).

🎥 Recording

Oldest entries are trimmed first once the cap is reached.

💾 Storage usage

—

Everything lives in chrome.storage.local on this machine. Nothing is uploaded, synced or sent anywhere — the extension declares no remote hosts and makes no network requests.

✂ Targeted deletion

☠ Nuke everything

Instantly and irreversibly clears the entire vault: every logged visit, every tab session and all in-memory tab bookkeeping. Your preferences on this page are kept.

There is no undo and no backup — export first if you want a copy.

⚠️ What this extension actually does

By design this tool makes Incognito browsing persistent, which is the opposite of what Incognito normally guarantees. Anyone with access to this Chrome profile can read the vault. Only install it on a browser you own, and tell the other people who use this computer that it is running — a private-browsing session that is silently logged is a nasty surprise. Use the retention setting or the nuke button to keep the window of stored data small.
